# Scenario soutenance (15 min)

## 1) Intro (1 min)
- Sujet choisi: gestion de restaurants + reservations
- Stack: PHP MVC + API REST + Flutter

## 2) Web admin/client (5 min)
- Login / register
- Creation restaurant (photo + map pour lat/lng)
- CRUD restaurant
- Recherche AJAX
- Validation admin (accept/refuse)
- Export PDF

## 3) API + Postman (4 min)
- Login API et recuperation JWT
- CRUD restaurants
- Routes protegees (`Authorization: Bearer ...`)
- Reservations
- Erreurs API (missing fields / forbidden / not_found)

## 4) Mobile Flutter (4 min)
- Liste restaurants (scroll 80% + pagination)
- Ecran details
- Creation restaurant avec:
  - camera
  - geolocalisation
- Mes reservations / mes restaurants

## 5) Securite (1 min)
- Prepared statements (anti SQL injection)
- JWT cote API
- CSRF cote formulaires web
- Hash mot de passe (bcrypt)
